# 知识库与风险规则

## 受控知识库

每个知识文档至少包含：标题、来源单位、发布日期、适用区域、草莓生育期、版本、审核状态、生效/失效时间、风险等级、审核人和引用片段。

状态流转为 `draft -> submitted -> approved -> retired`；仅 `approved` 文档可成为用户可见回答依据。

## 分级与行为

| 等级 | 含义 | 行为 |
|---|---|---|
| `low` | 常规且信息较充分 | 给出低风险排查和记录建议 |
| `medium` | 疑似病虫害/缺素或信息缺失 | 明确不确定性、补充信息、建议复核 |
| `high` | 可能扩散或严重症状 | 自动要求农技审核 |
| `blocked` | 农药剂量、混配、采收间隔等 | 不生成处方，转当地批准规则和农技审核 |

## 强制安全规则

包含农药剂量、配比、稀释、混配、间隔期或采收安全期等请求时必须返回 `blocked`。系统不得输出具体产品、浓度、剂量、次数或采收等待时间。

无图、图片质量不足或缺少棚室/生育期/近期管理时，初筛必须表达不确定性并要求补充信息。

## 草莓症状参考

| 类别 | 关键词 | 初步行动 |
|---|---|---|
| 白粉病 | 白粉、粉状、白色斑 | 补拍叶背，检查通风湿度 |
| 灰霉病 | 灰霉、灰色霉层、腐烂 | 隔离明显病果，优先审核 |
| 炭疽病 | 炭疽、褐色凹陷、黑褐斑 | 记录扩展速度，优先审核 |
| 根腐风险 | 根腐、红中柱、烂根 | 检查根系和积水，优先审核 |
| 蚜虫 | 蚜虫、蜜露 | 拍叶背和虫体 |
| 红蜘蛛 | 红蜘蛛、螨、网丝 | 拍叶背近景，检查高温干燥 |
| 蓟马 | 蓟马、银斑 | 拍花器和果实 |
| 缺钙 | 缺钙、焦边、果尖 | 补充水肥/EC 历史 |
| 缺铁 | 缺铁、黄化、叶脉绿 | 记录新老叶差异和 pH/EC |
| 盐害 | 盐害、烧根、叶缘焦枯 | 检查 EC、排水和近期施肥 |
| 水分胁迫 | 缺水、萎蔫、积水 | 记录墒情和灌溉 |

## 未来 RAG 接口

`KnowledgeProvider` 仅返回已审核文档片段及其元数据。未来 LLM 输出必须经过本规则后处理，附带来源，高风险问题进入审核流。
